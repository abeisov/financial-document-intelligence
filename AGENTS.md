# Project instructions

## Purpose

Terminal-first Financial Document Intelligence: извлечение финансовых показателей, поиск изменений и рисков, ответы строго по источнику.

## Current scope

- Сохранять рабочий CLI как контрольный и резервный путь.
- Разрешён локальный web-MVP для загрузки документов, индексации в RAGFlow и вопросов по источникам.
- Не добавлять регистрацию, платежи, многопользовательский режим или production-деплой без отдельного запроса.
- Начинать с небольшого цифрового PDF с известными контрольными значениями.
- OCR проверять отдельным тестом только для скана или изображения.

## Accuracy and safety

- Никогда не выводить API-ключи, пароли и заголовки Authorization.
- Не изменять `.env` без прямого запроса и никогда не добавлять его в Git.
- Не придумывать показатели, причины, риски, страницы и цитаты.
- Каждый существенный вывод должен содержать ссылку на страницу или идентификатор фрагмента.
- Если данных недостаточно, возвращать `insufficient_evidence`.
- Явно разделять извлечённые значения, вычисленные показатели и интерпретации модели.
- Не давать инвестиционных или кредитных рекомендаций от имени системы.

## Engineering rules

- Тестировать цепочку по этапам: извлечение → chunking → embedding → retrieval → reranking → Qwen.
- Проверять OCR и RAGFlow отдельными preflight-тестами.
- Обрабатывать таблицы, пропущенные значения, разные валюты, единицы измерения и периоды.
- Не логировать полный документ или чувствительные финансовые данные без необходимости.
- Сохранять обезличенные результаты в `artifacts/`.
- Перед завершением запускать тесты и предоставлять PASS/FAIL по каждому этапу.
- Не добавлять production-инфраструктуру без отдельного запроса.
